# FoodBlog - Кулинарный блог

## Описание проекта
Учебный проект, представляющий собой современное веб-приложение для публикации и просмотра кулинарных рецептов. Пользователи могут просматривать каталог блюд, регистрироваться, добавлять рецепты в «Избранное», а также создавать и удалять свои собственные рецепты. Сайт имеет полностью адаптивный дизайн.

## Стек технологий
* **Серверная часть (Web-сервер):** Python, Django.
* **Клиентская часть (Frontend):** HTML5, CSS3, Vanilla JavaScript.
* **Хранение данных:** LocalStorage.
* **Инструменты:** Figma.

## Порядок установки и запуска
1. Скачайте и распакуйте проект на свой компьютер.
2. Убедитесь, что у вас установлен Python.
3. Откройте терминал в корневой папке проекта.
4. Установите фреймворк Django (если он еще не установлен):
   `pip install django`
5. Выполните миграции служебных таблиц Django:
   `python manage.py migrate`
6. Запустите локальный сервер:
   `python manage.py runserver`
7. Перейдите в браузере по адресу: `http://127.0.0.1:8000/`

## Аналитическая часть
**Целевая аудитория:** Студенты, молодые специалисты и начинающие кулинары, которые хотят готовить простые и вкусные блюда,
 не тратя время на поиск рецептов по перегруженным рекламой сайтам.

**Бизнес-логика:** 
Сайт выступает в роли личной кулинарной книги. Пользователь заходит на главную страницу, где видит подборку популярных блюд.
Для полного взаимодействия ему необходимо пройти регистрацию или авторизацию. 
После входа у пользователя появляется возможность добавлять понравившиеся рецепты в избранное, формируя свой личный список,
а также создавать собственные рецепты, которые сразу появятся в общем каталоге и в его профиле. 
Удаление рецепта доступно только его автору.
